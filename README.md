# RE:WORK CENTER

RE:WORK CENTER는 상담사가 내담자 정보를 바탕으로 AI 상담 리포트 초안을 만들고, 검토·편집하여 상담에 활용할 수 있도록 지원하는 웹 서비스입니다.

AI가 생성한 내용은 상담을 돕기 위한 초안입니다. 실제 상담이나 문서 전달에 사용하기 전에 상담사가 사실관계, 표현, 개인정보 포함 여부를 반드시 확인해야 합니다.

## 주요 기능

### 사용자 화면

- 랜딩 페이지와 로그인·회원가입
- 상담 현황을 확인하는 대시보드
- 관리자 공지사항 조회
- 상담 업무와 현장 경험을 공유하는 한 줄 메모
- 사용자 계정 정보 확인 및 관리

### 리포트 생성

- 직업선호도검사 리포트
- 취업 성공사례 리포트
- 내담자 정보와 검사·상담 내용을 활용한 AI 초안 생성
- 생성된 리포트의 상담사 직접 편집
- 완성된 리포트 PDF 저장

기본 이용 흐름은 다음과 같습니다.

1. 로그인합니다.
2. 리포트 종류를 선택합니다.
3. 내담자 정보와 검사 결과 또는 상담 내용을 입력합니다.
4. AI 리포트 초안을 생성합니다.
5. 상담사가 내용을 검토하고 수정합니다.
6. 필요한 경우 PDF로 저장하여 상담에 활용합니다.

### AI 허브

AI 도구와 활용 자료를 한곳에서 참고할 수 있도록 준비하는 공간입니다. 현재 더 좋은 서비스를 제공하기 위해 점검 중입니다.

### 관리자 기능

- 공지사항 등록 및 관리
- 계정과 권한 관리
- 리포트 생성 현황 및 이용 통계 확인
- AI 요청 실패와 사용 이벤트 점검

## 실행 환경

- Node.js 18 이상
- npm
- Gemini API 키
- JWT 서명에 사용할 충분히 긴 비밀키
- PostgreSQL 데이터베이스(운영 데이터 저장 기능을 사용하는 경우)

## 로컬 실행

1. 의존성을 설치합니다.

   ```bash
   npm install
   ```

2. `.env.example`을 복사하여 `.env` 파일을 만들고 필요한 값을 입력합니다.

   ```env
   GEMINI_API_KEY=your_gemini_api_key
   JWT_SECRET=replace_with_a_long_random_secret
   PORT=3000
   ```

   PostgreSQL을 사용하는 환경에서는 다음 값도 설정합니다.

   ```env
   DATABASE_URL=your_postgresql_connection_string
   ```

3. 서버를 실행합니다.

   ```bash
   npm start
   ```

4. 브라우저에서 다음 주소로 접속합니다.

   ```text
   http://localhost:3000
   ```

## 관리자 계정 초기화

관리자 계정을 처음 생성할 때는 `.env`에 다음 값을 설정합니다.

```env
ADMIN_LOGIN_ID=your_admin_login_id
ADMIN_INITIAL_PASSWORD=your_secure_password
```

그다음 아래 명령을 실행합니다.

```bash
npm run init-admin
```

이미 같은 로그인 ID의 계정이 존재하면 기존 계정은 변경되지 않습니다.

## 테스트

인증 보안 관련 테스트는 다음 명령으로 실행합니다.

```bash
npm run test:auth-security
```

## 데이터와 보안 주의사항

- `.env` 파일과 실제 API 키, JWT 비밀키, 데이터베이스 접속 정보는 Git에 커밋하지 않습니다.
- 내담자의 민감정보는 상담 목적에 필요한 범위에서만 입력합니다.
- AI 생성 결과에는 부정확하거나 과도한 해석이 포함될 수 있으므로 상담사가 반드시 검토합니다.
- 운영 환경에서는 HTTPS, 접근 권한, 계정 상태, 데이터베이스 보안 설정을 함께 점검합니다.
- 사용 이벤트와 오류 로그에는 불필요한 개인정보나 인증정보가 기록되지 않도록 관리합니다.

## 오류 발생 시 확인 사항

- 리포트가 생성되지 않으면 네트워크 연결과 Gemini API 키를 확인합니다.
- 인증에 실패하면 `JWT_SECRET` 설정과 계정 상태를 확인합니다.
- API 사용량 제한이나 일시적인 서비스 장애가 발생하면 잠시 후 다시 시도합니다.
- 데이터가 저장되지 않으면 `DATABASE_URL`과 데이터베이스 연결 상태를 확인합니다.
- 상세한 사용 이벤트 구조는 `LOG_SCHEMA.md`를 참고합니다.

## 운영 상태 안내

화면의 기능 상태는 다음 의미로 사용합니다.

- 별도 표시 없음: 현재 사용할 수 있는 기능
- 점검 중: 개선 또는 안정화 작업이 진행 중인 기능
- 관리자 전용: 관리자 권한으로만 접근할 수 있는 기능
